# Processed Results

Each version directory contains the combined seed-level raw CSV, the summary
CSV with mean and 95% Student-t confidence-interval columns, and selected
manuscript-ready figures and tables.

- `v31`: principal zero-redundancy comparison and fallback diagnostics
- `v32`: equal-redundancy single-erasure reliability comparison
- `v33`: path/segment-bound sensitivity and compact debug aggregates
- `v34`: traffic-distribution sensitivity and paired statistical tests

The multi-gigabyte per-event debug checkpoints are omitted. They are
regenerated automatically by the corresponding simulator.
